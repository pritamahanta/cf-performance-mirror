CF Performance Mirror

Privacy Policy  ·  Browser Extension

✔  This extension does not send any data to the developer or to any server other than codeforces.com. All processing happens locally in your browser, and anything it stores stays in your browser.

1. Overview

CF Performance Mirror ("the Extension") is a browser extension that displays enhanced performance statistics on Codeforces profile pages and, if you turn them on, an Online Friends panel and a Friends submissions box in the Codeforces sidebar. This Privacy Policy explains what data the Extension accesses, how it is used, and your rights as a user.

This policy applies to all users of the Extension and was last updated on October 10, 2026.

2. Data the Extension Accesses

When you visit a Codeforces profile page (e.g. https://codeforces.com/profile/<username>), the Extension reads the following:

  • Codeforces username — extracted directly from the page URL you are already visiting.
  • Submission history — fetched from the public Codeforces API (codeforces.com/api/user.status) using that username.
  • Contest and rating data — fetched from the public Codeforces API (codeforces.com/api/contest.list and codeforces.com/api/user.rating).

All of this data is publicly available on Codeforces and is only retrieved for the purpose of rendering statistics within your browser.

The Online Friends panel is on by default and can be turned off with the Friends button in the profile page's controls. It only works while you are logged in to Codeforces. While it is on, the Extension also:

  • Loads https://codeforces.com/friends using your browser's existing Codeforces login session, the same way the site would if you opened that page. The Extension never sees, stores, or transmits your password or session token — only the list of friend handles that page shows.
  • Reads each friend's public profile page (the same "Last visit: online now" text anyone can see there) to tell who is online.
  • Asks the Codeforces user.info API about your friends' handles, to get their rating, rank and when each was last active. These requests are made by the Extension's background service worker.

The Friends submissions box is a separate option, also on by default (the Submissions button in the profile page's controls turns it off), and only works while you are logged in to Codeforces. It appears on problem pages of regular contests (not gym contests). While it is on and its box is open, the Extension:

  • Loads https://codeforces.com/friends the same way as above, to get your friends' handles.
  • Loads Codeforces' friends-only status page of the problem you opened (https://codeforces.com/problemset/status/<contest>/problem/<letter>?friends=on) using your browser's existing Codeforces login session, to see which of your friends have submitted it. Only the page's list of submissions is read, and the result is kept in memory for 2 minutes.
  • Asks the Codeforces contest.status API for the submissions of each friend who has submitted the problem (of every friend, when that page cannot be used) in the contest of the problem page you opened. Only the friend's handle and the contest id are sent, to codeforces.com.
  • Asks the Codeforces user.info API about your friends' handles, to colour them by rating. These requests are made directly from the page, not by the background service worker.

3. How Data Is Used

Data fetched from the Codeforces API is used exclusively to:

  • Calculate and display performance statistics (solve times, failure rates, rating changes) on the profile page you are viewing.
  • Remember your filter and display preferences locally using localStorage in your browser, including whether the Online Friends panel and the Friends submissions box are turned on and open.
  • If you turn on the Online Friends panel: show which friends are online, with their rating.
  • If you turn on the Friends submissions box: show which of your friends have submitted the problem you are viewing, and whether they solved it.

The Extension does not use this data for advertising, analytics, profiling, or any purpose other than rendering the on-page display.

4. Data Storage

The Extension stores your UI preferences (selected division, time range, display options) using the browser's localStorage API.

If you turn on the Online Friends panel, it also stores:

  • In localStorage, keyed to your logged-in Codeforces handle: your friends' handles, whether each was online and when that was checked, the rating and rank of friends shown as online, and when each friend was last active according to Codeforces. If the Extension cannot tell which account is logged in, it stores nothing. A stored list belonging to another account, or left from a logged-out state, is deleted the next time a Codeforces page that has a sidebar loads, even if the panel is turned off.

If you turn on the Friends submissions box, it also keeps:

  • In localStorage: a friend's submissions in the contest of the problem page you opened — submission id, problem letter, submission time, participant type, time since the contest started, verdict, test set and passed-test count — reused for up to 30 minutes; a friend's rating and rank, reused for up to 6 hours; and whether the box is turned on and open.
  • In sessionStorage (this browser tab only, gone when the tab is closed): your friends' handles, keyed to your logged-in Codeforces handle, reused for up to 5 minutes. Nothing is stored if the page does not show who is logged in.
  • In memory only: the same friends' handles, while the page is open.

All of this data:

  • Is never sent by the Extension to the developer or to any server other than codeforces.com.
  • Is stored in codeforces.com's own site storage, so scripts of codeforces.com itself can technically read it, as with any other data stored by that site in your browser.
  • Is not deleted when you turn the Online Friends panel off.
  • Can be cleared at any time by clearing your browser's site data for codeforces.com.

5. Data Sharing and Third Parties

We do not share any data with third parties. The only external communication made by the Extension is outbound requests to codeforces.com — the site you are already browsing. That includes the Codeforces API and, if you turn on the Online Friends panel or the Friends submissions box, your friends page and, for Online Friends, your friends' public profile pages. No data is sent to the developer or any analytics service. These are ordinary requests from your browser to codeforces.com, so Codeforces can see them the way it sees any page you load.

6. Permissions

The Extension requests the following permissions:

  • Host access to codeforces.com — required to inject the statistics panel into Codeforces profile pages and the Online Friends panel and Friends submissions box into Codeforces pages with a sidebar, and to make requests to the Codeforces public API and site pages.

No other permissions are requested or used.

7. Children's Privacy

The Extension is not directed at children under the age of 13. We do not knowingly collect any personal information from children. The Extension only accesses publicly available data on Codeforces.
